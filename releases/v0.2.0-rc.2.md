WordMath 现在可以通过 ChatGPT 账号生成 Word 公式、矩阵和证明。首次使用时在系统浏览器授权，后续直接在 Word 的输入面板选择模型。使用这个入口无需填写 API key 或启动 Codex。

## 下载与使用

- **Windows 11 x64**：下载本页的 `WordMath-0.2.0-rc.2-windows-x64-setup.exe`。安装包包含 .NET 运行时，预览需要 Microsoft Edge WebView2 Runtime。安装包尚未做 Authenticode 签名。升级前请从托盘退出旧版。
- **Apple Silicon Mac**：下载 `WordMath-0.2.0-rc.2-macOS-arm64.zip`。退出旧版，解压后将 WordMath 拖入“应用程序”。应用使用本地签名。

1. 在 Word 中将光标放到插入位置。Windows 按 **Ctrl+Alt+Shift+M**，Mac 按 **⌃⌘M**。
2. 在模型下拉框选择 **使用 ChatGPT 登录…**，点击登录按钮，然后在浏览器确认账号和套餐授权。
3. 回到面板，选择账号可用的模型，输入「给出哈密顿–凯莱定理的证明」。核对预览后再插入。打开设置前输入的内容会保留。

模型列表由 OpenAI 按当前账号和工作区返回。生成、追问和修复排版都会使用选中的服务。可以在下拉框中主动切换到已配置的 DeepSeek 等 API 服务，或从账号设置切换 ChatGPT 账号。选用 ChatGPT 时可以从面板打开[套餐用量设置](https://chatgpt.com/settings/usage)。

## 验证范围

自动化测试使用模拟授权服务和模型响应，覆盖浏览器回调、账号与模型绑定、授权续期、额度不足和流式输出中断。个人 ChatGPT 账号授权及线上生成仍待实测。Windows 的真实 Word 插入可从开始菜单的 **WordMath → Test Word integration** 检查。本版本按候选版发布。
