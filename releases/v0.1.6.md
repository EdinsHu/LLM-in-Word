WordMath 是配合 Mac 版 Microsoft Word 使用的菜单栏应用。在 Word 正文中按 **⌃⌘M**，用自然语言描述数学内容，预览并确认后即可插入原光标处。

## 这一版可以做什么

- 生成数学符号、分式、矩阵、联立方程、定理证明和简单表格。公式插入后仍可用 Word 的公式编辑器修改，说明文字沿用插入点的字体和字号。
- 在预览中点选并编辑文字或数学符号，也可以继续追问。输入和预览时均可拖动面板左上角的六点手柄，腾出空间阅读原文。
- 首次配置 OpenAI、DeepSeek、Anthropic 或兼容 API 后，即可在面板中切换已配置的模型。API 密钥保存在 macOS 钥匙串。
- 首次插入时，若 Word 询问是否允许访问 `insertion.docx`，请选择「允许访问」。后续插入会复用该文件。

## 安装与首次使用

1. 使用 **Apple Silicon（M 系列）Mac、macOS 13 或更新版本，以及桌面版 Microsoft Word**。下载附件 `WordMath-0.1.6-macOS-arm64.zip`，解压后把 `WordMath.app` 拖入「应用程序」。升级时请先从菜单栏退出旧版。
2. 打开 WordMath，在「模型设置」中配置服务和 API 密钥。这个安装包使用临时签名，未经 Apple 公证，首次打开时 macOS 可能提示无法验证开发者。
3. 在 Word 正文中单击插入位置，按 **⌃⌘M**，试试输入「给出柯西–施瓦茨不等式，并解释符号含义」。检查预览后按 **⌘Enter** 插入。首次使用时，按系统提示允许 WordMath 控制 Word。
