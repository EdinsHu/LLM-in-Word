WordMath 的首个 Windows x64 候选版，面向 Windows 11 和桌面版 Microsoft Word。

## 安装与使用

1. 下载本页的 `WordMath-0.2.0-rc.1-windows-x64-setup.exe`，双击安装。按当前 Windows 用户安装，已含 .NET 运行时；预览需要 Microsoft Edge WebView2 Runtime。安装程序尚未做 Authenticode 签名。
2. 启动 WordMath，配置模型服务，或先关闭设置用离线排版示例试用。模型密钥加密保存在本机。
3. 在 Word 正文中单击，按 **Ctrl+Alt+Shift+M**，例如输入「给出哈密顿–凯莱定理的证明」。预览可以拖动、点选修改或继续追问；按 **Ctrl+Enter** 将确认的文字、公式和表格插回原位置。

## 已完成的测试

- 在 Windows 构建机上实际安装和卸载附件，验证单实例、密钥读写和两种模型 API 协议。
- 运行真实 WebView2 面板，验证拖动、关闭设置后继续编辑、中文输入法确认、生成、修复错误内容块和针对选区追问。模型服务使用可重复的模拟响应。
- 核对哈密顿–凯莱定理证明的正文和 14 个原生公式的数据结构，检查预览、Word 文档片段、字体及字号。

## 桌面 Word 验收

构建机未安装桌面版 Word。开始菜单中运行 **WordMath → Test Word integration**，会在新的 Word 实例和临时文档中实际插入中文、原生公式和表格。它还会保存、重新打开完整证明，然后用 Word 编辑公式。测试报告保存在 `%LOCALAPPDATA%\WordMath\Diagnostics`。本版本保留候选状态，待完成已安装 Word 的 Windows 桌面验收。
