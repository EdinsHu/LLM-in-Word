# LLM in Word · WordMath

WordMath 是配合 Mac 版 Microsoft Word 使用的菜单栏应用。写到需要数学内容的位置，按 **⌃⌘M** 描述一个符号、矩阵或整段推导。预览并确认后，文字和可编辑的公式会插入原光标处。日常使用只需打开 Word 和 WordMath。

## 下载与安装

使用 Apple Silicon（M 系列）Mac 可从 [GitHub Releases](https://github.com/EdinsHu/LLM-in-Word/releases/latest) 下载安装包。解压后将 `WordMath.app` 拖入“应用程序”并打开。升级时请先从菜单栏退出旧版。

## 构建与启动

运行需要 macOS 13 或更新版本、桌面版 Microsoft Word。构建需要 Swift 6 工具链，可使用包含 Swift 6 的 Xcode Command Line Tools 或 Xcode 16 及更新版本。在仓库目录运行：

```sh
./scripts/build-app.sh
open dist/WordMath.app
```

启动后，菜单栏会出现函数符号。长期使用可将 `dist/WordMath.app` 拖入“应用程序”，再将它添加到“系统设置 → 通用 → 登录项”。

点击函数符号展开菜单，再点一次图标、点击菜单外或按 Esc 可以收起菜单。在 Word 中按 **⌃⌘M** 时只显示公式输入面板。需要调整账号时可从面板打开“AI 服务设置”，关闭设置后会回到原来的输入内容。设置窗口支持红色关闭按钮、**⌘W** 和 **Esc**。

WordMath 在同一用户会话中只运行一个实例。再次双击应用或执行 `open dist/WordMath.app` 时，会回到已有的输入面板或设置窗口。两个窗口都已关闭时，WordMath 会留在菜单栏待用。

从支持单实例之前的版本升级时，先点菜单栏中的函数符号，选择“退出 WordMath”。如果有多个 WordMath 图标，请逐个退出；也可在“活动监视器”中搜索 WordMath，退出剩余的旧进程。随后替换应用并启动新版本。

## 首次连接模型

1. 打开菜单栏中的“模型设置…”。首次运行会自动打开这个窗口。也可先在一份空白 Word 文档中放好光标，点「在 Word 中试用排版示例」体验本地预览和插入。
2. 从“添加服务”选择 OpenAI、DeepSeek、Anthropic 或自定义兼容服务，填写该服务的 API 地址和密钥。密钥保存在 macOS 钥匙串。这里使用 API 访问凭据，所需权限和费用以对应的 API 账号为准；聊天客户端的订阅或登录状态不会自动导入。
3. 点击“读取可用模型”。若服务未提供模型列表，手动填写服务端认可的模型 ID，多个 ID 用逗号分隔。选定默认模型后点击“保存设置”。可重复添加其他账号。
4. 首次唤起输入框时，允许 WordMath 自动化控制 Microsoft Word。可在“系统设置 → 隐私与安全性 → 自动化”查看授权。若希望面板紧贴文本光标，点击菜单栏的“启用光标定位…”，按提示授予辅助功能权限。无法读取光标坐标时，面板会显示在鼠标附近，写入目标仍取自 Word。
5. 升级到 0.1.5 后，首次点击“插入 Word”时，如果 Word 请求访问 `insertion.docx`，请选择“允许访问”。以后插入会复用同一文件，包括重新启动 WordMath 以后。文件位于 `~/Library/Application Support/WordMath/Insertion/insertion.docx`，正常插入结束后内容即清空。手动删除该文件或重置 Word 的授权后，下次插入可能需要重新允许。

## 在 Word 中写作

在可编辑文档的**正文中单击一下**，使光标闪烁，然后按 **⌃⌘M**。快捷键仅在 Word 位于前台时启用，也可从菜单栏选择“在 Word 中输入…”。

按住输入面板左上角的六点手柄即可拖动。可以在描述公式时或预览生成后移动面板，插入位置仍是唤起时的 Word 光标。关闭面板后，在别处重新唤起会跟随新的光标。

| 操作 | 结果 |
| --- | --- |
| 输入“生成二阶矩阵的特征多项式，用一句中文说明符号含义”，按 Enter | 展示正文与公式的混排预览 |
| 点选预览中的文字或数学符号，修改后点“应用” | 在本机修正当前预览 |
| 点“继续修改”并补充要求，或选择“针对选区追问” | 将最新预览和要求交给当前模型更新 |
| 在模型选择框中换一个模型 | 下一次生成或追问使用该模型；切换本身不发出请求 |
| 按 ⌘Enter 或点“插入 Word” | 把当前预览写入 Word |
| 按 Esc | 退出当前编辑或取消面板 |

生成前，输入框中的「模型名 · 服务名」表示本次请求的实际去向。收到服务的有效响应后，面板会显示 HTTP 状态，以及服务回传的模型名称和 token 用量（如有）。可以用这行回执核对服务调用，金额以该服务的账单为准。

WordMath 会从模型回复中提取排版文档，并在本机转换可明确识别的等价写法。例如，模型用 `{"type":"symbol","value":"x"}` 表示符号时，可以直接预览。

如果仍有结构错误，面板会显示第几个内容块、具体 JSON 路径，以及该位置需要的格式。点击「修复排版」会向原模型发送一次请求。若能定位到内容块，只请求修复有错的块，随后在本机与通过校验的段落、公式和表格合并。若连内容块都无法识别，才请求模型整理整份回复。修复失败后，面板显示本次失败原因，是否再次调用由你决定。待修复内容只临时保存在当前面板中。

数学符号、上下标、分式、根式、矩阵和联立方程可写为 Word 原生公式。定理、证明和推导可由正文、行内公式与独立公式组成，也支持简单的原生表格。说明文字使用插入点前的字体、字号等格式；在段首取当前位置的格式。预览用于检查内容与结构，实际分页和换行由 Word 排版。

当前写入目标为活动文档正文中的单一插入点。请先取消文字选区；页眉、页脚和脚注等位置暂不支持。若预览期间移动了光标、切换文档或改变了插入位置附近的内容，应用会提示在目标位置重新唤起面板。

## 验证

```sh
./scripts/test.sh
swift Tests/Panel/run.swift
```

在已登录的 Mac 图形会话中，可单独运行真实 Word 写入测试。它会创建并关闭专用测试文档，运行期间请让该文档保持活动，并允许所提示的 Word 自动化访问。

```sh
WORDMATH_LIVE_TEST=1 ./scripts/test.sh --filter testLiveInsertion
```
